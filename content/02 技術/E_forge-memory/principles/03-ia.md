# 導覽 IA:三架構分組保留,葉子換 dev

按「開發者做什麼」排葉子,不按零件排。三架構分組保留(三層都在一線),
但葉子全是 dev 原生(實作於 `ui/src/forge.config.ts`):

- **Agent 大腦**:對話 console · 準則 rubric · 提案 designer
- **n8n 迴圈**:執行 runs · 編排 flows · 審查 review
- **Vault 資料·記憶**:目標 targets · 經驗 memory · 焦點 now
- utility:觀測 signals · 設定 settings

n8n 的**連線**是設定(細項);n8n 的**工作流本身**是一級的門(`編排 flows`),
直通 n8n 本尊——不重做假的。
