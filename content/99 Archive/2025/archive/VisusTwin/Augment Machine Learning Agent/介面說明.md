## 1️⃣ CrewAI Studio 介面區塊設計說明

### 1. **Crews 團隊**

- **定義一組協作的 Agent 團隊**（可混合多種角色，每個 Agent 可指定不同工具、任務偏好）
    
- 適合**跨多步驟/多角色的自動化 pipeline**設計
    
- 例：一個 ML training crew 可以有「Data Preparer、Trainer、Evaluator、Tuner」等 agent
    

### 2. **Tools 工具**

- **所有可被 agent 調用的外部工具/腳本/函式**
    
- 可以是你自訂的 python 工具、API 呼叫、外部服務
    
- 每個工具可以 expose 設定參數，讓 agent 組裝任務時自由組合
    

### 3. **Agents 代理**

- **單一智能體（AI/腳本/任務分工角色）**
    
- 每個 agent 可指定擅長工具、行為模式、知識庫、任務偏好
    
- 例：訓練 agent 只會用 train.py，標註 agent 專用分割腳本
    

### 4. **Tasks 任務**

- **具體要執行的工作**（可單步/多步/串接）
    
- 指定用哪個 agent+tool+參數組合
    
- 支援 pipeline 設計（多步驟串接）、任務分拆/多工處理
    

### 5. **Knowledge 知識庫**

- **系統可用的知識、範本、提示語、文件**
    
- 讓 agent 可引用知識做任務規劃/回應增強
    
- 例：存放你的 ML baseline、數據規範、超參數範本
    

### 6. **Kickoff! 啟動！**

- **一鍵啟動指定 pipeline/crew 的所有任務**
    
- 啟動後 agent 會按排定流程自動分工執行
    
- 適合自動批次運算、大規模測試
    

### 7. **Results 結果**

- **所有任務的 log、運行狀態、執行結果匯總**
    
- 可以瀏覽、下載、查詢歷史運算結果、報表、可視化分析
    

### 8. **Import/export 匯入/匯出**

- **導入外部任務/設定/資料，或將 agent、tool、results 導出**
    
- 支援設定跨專案複用、備份、與團隊/客戶共享
