# manager · 駕駛艙建置決策(2026-06-30)

> 完整現況快照見 [[Manager|超級 App/Manager]];本檔是精煉的決策紀錄。

## 是什麼
經理型 macOS 超級 app:把 **n8n(編排)+ claude agent(大腦,經 bridge)+ vault(真相)** 收進一個原生殼。

## 關鍵決策
- **模組框架**:側邊欄由「模組註冊表」生成 —— 駕駛艙 + Agent / n8n / Vault 三柱;加模組 = 註冊表加一筆(後續演進成 bridge `/modules` 資料驅動,免重編)。
- **殼 = 原生 SwiftUI · 內容 = web 模組頁**(n8n webhook 回 HTML)。不全 native(ROI 差、丟掉重用)。
- **設計系統**:對齊 `02 技術/Design-System` —— zinc 中性 + 單一 signal 綠(≤5% 視野)· HUD 語彙 · 無 emoji · 跟隨系統明暗;蒸餾成 `web/vistwin.css` 共用,各模組頁 inline。
- **資料層**:host bridge(`:8787`,launchd,**讀寫 vault — TCC 沒擋**);n8n(`:5678`,Docker)。
- **可編輯儀表板**:bridge `/project/{update,create,delete}` —— 只改 frontmatter、**保留 body**、house-style 序列化、原子寫入、token-gate、路徑守門;人手編輯走「小確認」,git 當還原網。

## 踩過的雷(別再犯)
- **n8n 的 SQLite 不要從主機改**:容器開著時改 → WAL/shm 跨主機-容器不同步 → `SQLITE_IOERR`。要嘛停容器(備份 → 停 → 寫 → 起),要嘛走 n8n CLI / API。
- **n8n 等待表單用「該次執行的快照」渲染** → 改 `customCss` 只對**新**執行生效,舊的維持原樣。
- **zsh 的 `$path` 是特殊變數**(綁 `$PATH`):腳本別用 `path` 當變數,會清掉 PATH。
- **WKWebView 的 `.ignoresSafeArea()` 會讓內容畫到側邊欄底下** → 拿掉才不會蓋住。
- **token 不進 git**:產生器把 `BRIDGE_TOKEN` 注入頁面 → 那個 `.json` 要 gitignore。
- **n8n 資料夾樹狀瀏覽 UI 要免費 registered-community 金鑰**;資料夾資料本身可直接用,tag 免授權。

## 後續方向
- 對話管 n8n(`op:n8n` + API key + 四層風險閘);記憶接進 `/ask`;監控(讀 + 告警)先做;LINE outbound 免 tunnel、雙向要 tunnel;**Claude Desktop + 本機 MCP = 最無痛的「用嘴控」**;自我開發已上線(分支思路 + 驗證 + watchdog rollback)。
