# 🧠 Skill Learnings

> 借自 founder-os「institutional memory」模式。每個 skill 用過後在自己的
> `## Lessons` 補一行，這裡自動彙整。fresh session 不從零開始。

## 各 skill Lessons 彙整

```dataview
TABLE WITHOUT ID
  file.link AS "Skill",
  file.mtime AS "Last Edit"
FROM "00 系統/技能"
WHERE file.name = "SKILL"
SORT file.mtime DESC
```

> Dataview 無法跨檔抓 section 內文，逐 skill 點進去看 `## Lessons`。
> 跨 skill 的通用教訓 → 手動沉澱到下面。
