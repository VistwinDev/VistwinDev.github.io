# 共用治理原則

> 跨 manager-mac 與 dev-windows 都適用。

## 角色分工
- **人 = 導演**(意圖 + 判真假 + 拍板)
- **agent = 手**(讀 / 寫 / 連結 / 維護)
- **vault(.md / git)= 唯一真相**
- **app = 控制 + 審閱**

## 資料即整合層
- 一切建在 markdown-on-git,不進專有 DB → **反鎖定**;工具(app / Obsidian / agent / 未來 web)變成「按任務挑鏡片」,不是「一個工具統治一切」。

## 安全模式
- **提案 → 核准 → 套用**:agent 批次改動走此閘;人手即時編輯走「小確認」,git(每 5 分自動 commit)當還原網。
- 寫 = 確定性 frontmatter 編輯:**只動 frontmatter、不碰內文**;改名只改 `title` 欄、不動檔名(避免斷 `[[連結]]`)。

## 規模化的真瓶頸
- 「寫」成本歸零後,**審與信(review / 核准 / ground-truth)才是真產品**。agent 越強,這層越是命門 —— 別讓 vault 爛成「看起來很對的胡說八道」。
