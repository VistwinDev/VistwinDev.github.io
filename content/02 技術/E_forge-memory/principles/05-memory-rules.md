# 記憶規則

- **ExperienceRecord = 情境 + 決策 + 結果 + 判決**(缺一不可)。不是「做了 X」,是「在什麼情境做了 X、結果指標如何、Critic 怎麼判、為什麼」。
- **依情境召回**(retrieval-by-situation):不是關鍵字比對,是「我這處境過去哪幾次最像」。召回結果**必須真的改變下一步動作**(餵進 Designer 提案),否則記了等於沒記。
- **會遺忘才是活的**:supersede(舊檔標 `superseded_by`)、降權、確認錯誤才刪、週期蒸餾成 lesson。
- **reference vs experience**:reference = 固定規則(準則/rubric);experience = 我們試過什麼。Critic 用 reference 判,Designer 用 experience 找靈感。
- **三類記憶**:`principles`(準則,少變)/ `status`(狀況,會變)/ `experience`(每輪)。
