# 🔌 Anthropic 官方 Plugin 對位表

> **不是工作流，是「決定要不要自己寫 skill 前」的對位表。**
> 安裝由使用者在 UI 做，這裡只做戰略對位。
> 來源：Anthropic 官方 plugin Directory（screenshot 可見 12 個 category）。

## 原則：官方 > 自寫

> 若某官方 plugin 內含 skill X 與我們自寫 skill Y 重複 → **優先用官方那個**。
> 自寫 skill 退成 thin wrapper 或刪除。理由：見 [[working-with-frncs/SKILL|working-with-frncs]] §0/§6
> — AI 半成品狀態，官方會持續吃掉自寫工具，不重新發明。
