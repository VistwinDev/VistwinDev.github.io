## 三、色彩

- 全案主色為 zinc 灰階 + **唯一品牌綠**。
- 品牌綠 = **Pantone 376 C**（CMYK 近似 `C50 M0 Y100 K0`）。**綠只出現在：大標與小字標的 `{ }` 括號、公司名圓點 `●`、網址箭頭 `↗`；白版另有前後對齊的兩條綠槓**。其餘一律黑/白/灰，綠佔比 ≤5%。
- 深底建議 rich black `C60 M50 Y40 K100`（依貴廠標準微調）。

## 四、加工工藝（霧底 + 亮字）

概念:**霧面基底 + 亮面文字**——霧底襯托,文字用上光或燙箔做出反光/微凸對比,精品觸感。
兩版因基材(白底深字 / 黑底亮字)不同,亮字工法也不同:

### 白版（vistwin-card-white-*）
- **紙材**:霧面棉卡 350–400 gsm(消光、棉感)。
- **文字/logo(深色)** → **局部 spot UV（上光)**:在黑/灰字上打透明亮油,字色不變、變亮、微凸、會反光。
  深色字不宜燙箔,spot UV 才對味。
- **綠 `{ }` 括號 + 圓點 + 箭頭** → **燙綠箔(Pantone 376C)** 點睛(或印綠 + spot UV)。

### 黑版（vistwin-card-black-*）
- **紙材**:霧面黑卡 350–400 gsm(消光、厚挺)。
- **文字/logo(白/亮字)** → **燙白箔**:霧黑底印白墨易發灰,燙白才乾淨反光,最接近你要的「燙」感。
- **綠 `{ }` 括號 + 圓點 + 箭頭** → **燙綠箔(Pantone 376C)**。
- 多道箔需**套準對位**(綠括號要正好框住字母)。

### 小字工法限制(務必先與印廠確認)
- 卡上最小字約 **4–5 pt**(tagline 英文 HUD 那行)。**燙箔 / spot UV 在此級數很容易糊、對位跑掉**。
- 建議:**大元素**(大標、許峰銘、名字、電話)才上光/燙箔;**最小那行(tagline 英文)維持平印霧面**,不上光不燙。
- 送印前請印廠確認貴廠工法在各字級的實際可行性。

## 五、裁切 / 角

- （VISIONbase 用圓角;VisTwin 刻意銳角,做品牌區隔。）
